# Swan Creek Gardens website

A static website (HTML, CSS and JavaScript, no build step) for Swan Creek Gardens, an award-winning garden wedding venue in the Chishawasha Hills, Harare.

- `index.html`: the homepage
- `styles.css`: the brand styles (colours and fonts from the Swan Creek brand guide)
- `script.js`: video loading, the phone menu, and the enquiry form (it opens WhatsApp with the details filled in)
- `assets/`: logo, photos, video posters and videos

To run it, serve the folder with any static web server. On Replit it runs as a static site with `index.html` as the entry page.

Editing tips: keep text changes in `index.html`; brand colours live at the top of `styles.css`; the WhatsApp number is at the top of `script.js` and in the `wa.me` links in `index.html`.
